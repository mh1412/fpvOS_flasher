Installing fpvOS on a stock BETAFPV P1?

Let the stock P1 finish starting after power-on, then click Connect above and pick its Sirius port: the flasher recognises a stock P1 and starts the restart below for you. You can also run the steps by hand here. Keep external power connected and disconnect other Artosyn devices.

The same P1 appears as a serial port, a USB bootloader, then a recovery serial port. Your browser asks for permission for each USB mode. Once fpvOS is installed, Connect reaches it directly and this panel is not needed again.

Select its Sirius serial port.

Select the same P1, now called USB download gadget.

Stuck in USB download mode from an earlier try? Power-cycle the P1 to return it to stock, then start again from Connect.

Stock preparation requires desktop Chrome or Edge with Web Serial and WebHID.

After recovery starts, click Connect above, select the P1 Air serial port, choose your firmware below and click Flash.

Preparation runs in RAM; it does not replace the bootloader. Tested on Linux Chromium; Windows and macOS are not yet verified. Linux may need USB/HID permissions: setup and recovery guide.

    How it works

    The page talks to the updater that already runs on the device, the same one the vendor's PC tool talks to, and checks the image before anything is sent.

    Ascent Lite/Lite+: the unit reboots into its update system, checks the transfer MD5 and image CRC, and updates banked components. Boot and environment can be written in place; this is not a whole-system atomic update.

    Standard Ascent VRX: use external DC power and USB. The page checks the signed OTRA container, SHA-256 and the standard VRX RSA key. The receiver applies its own authentication and hardware checks, then writes both single and paired NAND partitions. Persistent application changes may be replaced. VRX Pro and Avatar images need different profiles.

    BETAFPV P1 Air · Stock / fpvOS: select a full P1 .fwu bundle. The unit enters clean recovery, installs and verifies the image, then reboots. Keep external power connected. For initial installation from stock 1.0.44, use the browser preparation controls in the Device panel first. Stock images and VRX bundles are not supported by this profile.

    Close the vendor's PC tool and any serial terminal first: only one program can use the port.

    On Linux your user needs access to /dev/ttyACM* (the dialout group), and ModemManager, if it runs, can grab a new serial port for a few seconds.

    Advanced

    Ask the connected Ascent updater to enable USB network (RNDIS) mode. The standard VRX already exposes networking alongside serial. An air unit leaves serial mode until it reboots.
